# Photography Portfolio

A modern, immersive photography portfolio with continuous GSAP-driven mechanical camera shutter navigation, 3D works wheel gallery, and editorial layouts.

## Tech Stack

- **TanStack Start & TanStack Router**
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **GSAP** (GreenSock Animation Platform)
- **Vite**

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
